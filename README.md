# twiview

日本語 | [English](README.en.md)

Twitch を見やすくする非公式の Android アプリ。

> [!WARNING]
> Twitch とは無関係の**非公式アプリ**。再生や検索は Twitch Web 版の非公開 API を使っているので、Twitch 側の変更である日急に動かなくなるかもしれない。自己責任で。

## できること

公式アプリの再生まわりの機能(再生速度、音声のみ、スリープタイマー、バックグラウンド再生、続きから再生、PiP)はひととおり入れたうえで、公式には無い次のことができる。

- 一覧の情報密度が高い。1 画面に多く並ぶ
- 弾幕
- チャットの見た目を細かく変えられる(名前の省略と揃え、バッジ、エモート、時刻、行間、区切り、削除コメント)
- ワードとユーザーのブロック
- 低遅延モード。止まらない範囲で遅れを自動で詰める
- 横画面の「映像フィット」。チャットを残したまま映像を最大化
- ジェスチャーの割り当て変更(スキップ秒数、長押しの倍率、スワイプの左右)
- ログイン不要のお気に入り(ブックマーク)
- チャンネルポイントのボーナス自動受け取り
- マルチビュー。最大 4 配信を同時に(実験的)

**見る**
- フォロー中のチャンネル(要 Client ID、後述)と、アプリ内のお気に入り(ブックマーク、ログイン不要)を別の一覧で。配信中 / オフラインに分けて、視聴者数・開始時刻・配信時間・名前で並び替え
- チャンネル画面にアーカイブ一覧、本家と同じ週のスケジュール表、クリップ(期間で絞り込み)
- 人気と検索(カテゴリ一覧は検索タブの中)。`twitch.tv` と `clips.twitch.tv` のリンクをそのまま開ける

**再生**
- ライブも過去配信も同じ画面。過去配信はシークバーと 10 秒戻し・送り
- 低遅延 / 標準 / 安定。低遅延は作りかけの区切りまで読んで、遅れを 2 秒台まで詰める(回線次第)
- 画質は自動か 1080p〜160p。横画面はチャット幅固定と「映像フィット」の 2 種類。PiP には再生 / 一時停止と 10 秒スキップのボタン付き
- 再生速度(0.5〜2 倍)、音声のみ、スリープタイマー、バックグラウンド再生(常時 / ヘッドホン接続時)、続きから再生(一覧に視聴済みバー)
- ダブルタップで左右スキップ、長押しで倍速(離すと戻る)、上下スワイプで明るさと音量、横スワイプでシーク。割り当ては設定で変えられる
- マルチビュー(下のタブ)。配信中のフォロー・人気・検索から選んで最大 4 配信を同時に表示。窓ごとに上下スワイプで音量、タップで大きい窓とチャットを切り替え、並びは 3 種類から選べる。実験的な機能
- 広告は公式と同じ扱い。サブスク中のチャンネルで出ないのは Twitch のサブスク特典

**チャット**
- 文字サイズ、名前の色と省略、バッジ、エモート、時刻、行間、区切り、削除コメントの扱いを全部いじれる
- 弾幕。エモートも画像で流れる。濃さ・速さ・サイズ(画面の高さに比例)・範囲・同時表示数を調整できる
- ワードとユーザーのブロック。ログイン中は投稿もできる
- 過去配信は当時のコメントが再生位置に合わせて流れる

**チャンネルポイント**
- 視聴ポイントが貯まる(公式プレイヤーと同じ視聴報告を送っている)。ボーナスは自動で受け取る(後述の通りまだ怪しい)

## 入れ方

Android 8.0 以上。iOS は無い。

[Releases](https://github.com/s-tyd/twiview/releases) の APK を入れる。「提供元不明のアプリ」の許可が要る。

自分でビルドするなら JDK 17 で

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

自前ビルドは署名が違うので、Releases の APK とは上書きし合えない。

## フォロー一覧を出すには

フォロー一覧だけは Twitch 公式 API(Helix)で取るので、各自の Client ID が要る。

1. [Twitch Developer Console](https://dev.twitch.tv/console/apps/create) でアプリを登録
2. 発行された Client ID を「設定 → アカウント → フォロー用 Client ID」に入れる

自分でビルドする人は `local.properties` に書いておくと初期値になる(git 管理外)。

```properties
twitch.clientId=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## ログインとデータ

- ログインはアプリ内で開く twitch.tv 本体のページ。パスワードはアプリに渡らない
- トークンは端末の中だけ。Android Keystore で暗号化して、バックアップにも入れない。送り先は Twitch だけ
- 再生・検索は twitch.tv の Web 版と同じ公開 Client ID で問い合わせる。自分で登録した Client ID はフォロー一覧にだけ使う
- チャットを開いた直後の直近コメントは [recent-messages.robotty.de](https://recent-messages.robotty.de/) から取る(送るのはチャンネル名だけ)
- ログアウトでトークンと Cookie は消える

## 補足

- 低遅延は 2〜3 秒が限界。Web や公式(1 秒前後)には届いていない
- ボーナスの自動受け取りは、見えない WebView で twitch.tv のポップアウトチャットを開いてボタンを押している
